## Overview

Module 1 introduced the fundamental concepts of Kotlin programming. The main focus was understanding variables, data types, values, strings, Boolean values, and basic operations.

The exercises provided practical examples that showed how different types of information are stored and used in a Kotlin program.

## 1. Variables in Kotlin

One of the first concepts learned was how to declare variables.

Kotlin provides two main keywords:

- val
- var

A `val` variable is used when the value should not be reassigned after initialization.
A `var` variable is used when the value may change during program execution.

For example:
val name = "Sara"
var count = 10
