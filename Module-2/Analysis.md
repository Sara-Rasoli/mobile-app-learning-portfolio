## Overview

Module 2 focused on the basic structure of Kotlin programs and how instructions are executed.

The exercises were simple but important because they introduced the basic syntax used in Kotlin programs.

## 1. The main Function

A Kotlin program can contain a `main()` function that acts as an entry point for program execution.

For example:
fun main() {
    println("1")
    println("2")
    println("3")
}
