## Overview

Module 3 introduced functions in Kotlin.

Functions are important because they allow programmers to organize code into reusable blocks. Instead of writing the same instructions repeatedly, a function can be defined once and called whenever it is needed.

## 1. What is a Function?

A function is a block of code designed to perform a particular task.

A simple function can be written as:
fun birthdayGreeting() {
    println("Happy Birthday, Rover!")
    println("You are now 5 years old!")
}
