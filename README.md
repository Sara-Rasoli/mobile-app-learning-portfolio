## About This Portfolio

This repository contains my learning portfolio for the Mobile Application Development course.

The portfolio documents my progress in learning Kotlin and the fundamental programming concepts required for Android application development. It contains source code, analysis, screenshots, learning evidence, references, and personal reflection.

The portfolio is organized into four learning modules. Each module contains the source code completed during the learning activities together with an analysis of the concepts learned and the problems encountered.

## Learning Objectives

Through this portfolio, I aimed to:

- Understand the basic syntax of Kotlin.
- Learn how to declare and use variables.
- Understand Kotlin data types such as `Int`, `Double`, `String`, and `Boolean`.
- Understand the difference between `val` and `var`.
- Use string concatenation and string templates.
- Understand the structure of a Kotlin program.
- Use `println()` to display program output.
- Create and call functions.
- Understand parameters and arguments.
- Return values from functions.
- Apply arithmetic operations in Kotlin.
- Identify and correct common programming errors.
- Write reusable and more organized code.
- Build a foundation for Android application development.
