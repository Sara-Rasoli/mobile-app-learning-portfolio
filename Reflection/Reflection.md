## Introduction

This portfolio documents my learning progress throughout the Mobile Application Development course.

At the beginning, I was mainly familiar with programming concepts from other programming languages, but I needed to become more comfortable with Kotlin syntax and the way Kotlin is used for Android development.

The four modules helped me gradually build this knowledge.


## Module 1 Reflection

Module 1 helped me understand the basic building blocks of Kotlin.

I learned how to declare variables using `val` and `var` and how different data types are used for different kinds of information.

The exercises involving `Double`, `String`, and `Boolean` helped me understand that the type of a variable affects how the value behaves.

One important lesson was the difference between `val` and `var`. I learned that `val` should be used when a value does not need to be reassigned, while `var` is appropriate when the value needs to change.

I also learned about string templates, which make it easier to include variable values inside text.


## Module 2 Reflection

Module 2 helped me become more comfortable with the basic structure of a Kotlin program.

I learned how the `main()` function works and how `println()` is used to display information.

Although the exercises were simple, they helped me understand the importance of statement order and correct syntax.

This module gave me more confidence when writing and running small Kotlin programs.


## Module 3 Reflection

Module 3 was an important step because I learned how to create reusable functions.

Before learning functions properly, I mainly thought of a program as a sequence of statements. Functions helped me understand that a program can be divided into smaller tasks.

I learned the difference between parameters and arguments, and I learned how functions can return values.

The calculation examples using `add()` and `subtract()` helped me understand how information can be passed into a function and how the result can be returned.


## Module 4 Reflection

Module 4 helped me apply the concepts from the earlier modules to problem-solving.

The exercises showed me that small differences in data types can significantly change the result of a program.

For example, I learned that `"20"` and `20` are not the same because one is a string and the other is an integer.

I also learned the importance of avoiding unnecessary repeated code. The weather example showed how a function can be used to handle the same task with different inputs.

This module improved my ability to read code and identify the reason why an output may not be what I expected.


## Overall Learning

Throughout these modules, I developed a stronger foundation in Kotlin programming.

The main concepts I learned include:

- Variables
- Data types
- `val` and `var`
- Strings
- String templates
- Boolean values
- Arithmetic operations
- Functions
- Parameters
- Arguments
- Return values
- Code reuse
- Basic debugging

I also learned that understanding the reason behind an error is more useful than simply changing the code until it works.
